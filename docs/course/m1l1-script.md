What's the difference between an agent and a chatbot?

Well — a chatbot makes one call to a model, and that's it.
It shows you the answer, and it stops there.

An agent does a bit more.
It makes the call, reads the result, and decides what to do next.
Then it acts.

So an agent has two parts.
An LLM that decides, and tools — search, code, APIs.
But a chatbot can have those too.
So that's not quite the difference.

The difference is the loop.
The agent thinks: what should I do next?
Then it acts, calls a tool, reads the result, and repeats.

Every pass, the tool result feeds back into the model.
So the agent knows a little more each time.

So an agent is an LLM, a loop, and tools.
Take the loop away?
Then it's just a chatbot with extra steps.
