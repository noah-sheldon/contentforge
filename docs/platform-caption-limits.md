# Platform Caption Limits (verified Aug 2026)

Single source of truth for caption character limits. Caption-writing skills and agents MUST respect these.

| Platform | Limit | Visible before "more" | Hashtags | Notes |
|---|---|---|---|---|
| Instagram | 2,200 | ~125 chars | 30 max, 3-5 recommended | Line breaks work, first line is the hook zone; editable after posting |
| TikTok | 4,000 (native app); 2,200 via API/schedulers | ~39-100 chars (user observed ~39, research ~100) | No official cap; 3-5 best practice | Editable after posting |
| YouTube Shorts | **5,000 (web/Studio — Noah's upload path)**; mobile app entry caps at 100 | ~100-150 chars | Max 15 in description | Shorts have no separate title — description acts as title. Upload via web/Studio. First ~100 chars visible in feed regardless |
| Facebook | 63,206 | ~477 chars | 2-3 consensus | Editable anytime |

## Design rules

- Captions are EXTREMELY DETAILED by default — context paragraph, every point expanded, save CTA, series tease; max out the platform limit.
- First ~100 chars = hook + save CTA. Every platform truncates in the feed.
- Full breakdown goes below the "more" fold.
- Detail drives saves, comments, and reading time (session signals). Video watch time is owned by the video, not the caption.
- Add 1-2 emojis at post time only, never in repo files.
