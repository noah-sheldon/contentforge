# Lucide Icons

Use for all role representations, concept icons, and data annotations. Never use emoji.

## Install

```bash
npm install lucide-react   # for React dev; for HyperFrames paste the SVG path directly
```

## Usage

Inline SVG paths in composition HTML (Lucide icons are MIT, stroke-based):

```html
<!-- Inline in a clip: -->
<svg width="64" height="64" viewBox="0 0 24 24" fill="none"
     stroke="#D4AF37" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
  <path d="M12 3a3 3 0 0 1 3 3c0 .5-.1 1-.3 1.4l4.2 4.2..."/>
</svg>
```

Animate with GSAP on the wrapper (opacity/scale) like any other element.
