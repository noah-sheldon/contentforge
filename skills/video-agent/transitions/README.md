# Transition System

5 transition types that rotate. Never repeat same type in two consecutive videos.

## Types

| # | Type | CSS | Duration | When |
|---|---|---|---|---|
| 1 | Zoom Out | scale 1.0->1.12 + blur 0->4px | 6f | Energetic shifts, hook->BTS |
| 2 | Blur Morph | blur 0->8px clip end, 5->0 next start | 10f | Tone changes, setup->points |
| 3 | White Dip | White overlay opacity 0->1->0 | 10f | Aspirational moments, before CTA |
| 4 | Slide Split | Current slides left, next slides right | 8f | Side-by-side comparisons |
| 5 | Flash Frame | Single white frame (2f) + black (1f) | 3f | Pattern interrupt, re-engagement |

## Rules

- Never use same transition type twice in a row
- Hard cut is DEFAULT (70%+ of all cuts)
- White Dip max 1 per video
- Flash Frame max 2 per video
- Keep 1 deliberate black breather before CTA (30f)
- Keep 1 post-credits fade (15f)
